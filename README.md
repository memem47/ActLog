# ActLog

PC・Androidで使う個人用の行動記録Webアプリ。HTML/CSS/JavaScriptだけで動作し、データは個人用OneDriveのアプリ専用フォルダに保存します。

## 機能（初期版）
- ワンクリックで活動を1回記録
- 活動項目の追加、自由記述メモ
- 記録の編集（メモ）・削除
- 今日の回数、直近50件、JSONエクスポート
- Microsoftアカウント認証・OneDrive同期
- PC・Android対応のレスポンシブ画面

## 初期設定
1. Microsoft Entra 管理センターでアプリを登録します。個人用Microsoftアカウントに対応するアカウント種別を選択します（例：個人用Microsoftアカウントをサポートする設定）。
2. **認証 > プラットフォームを追加 > シングルページアプリケーション（SPA）** で次のリダイレクトURIを追加します。
   - `https://memem47.github.io/ActLog/`
   - ローカル開発時は `http://localhost:8765/`（使用するポートとURLに合わせる）
3. **APIのアクセス許可 > Microsoft Graph > 委任されたアクセス許可** で `Files.ReadWrite.AppFolder` を追加します。
4. 登録画面の「アプリケーション（クライアント）ID」をコピーします。**クライアントシークレットは作らず、ソースコードにも置かないでください。**
5. GitHubリポジトリの **Settings > Pages** で `Deploy from a branch`、ブランチ `main`、フォルダ `/(root)` を選択します（本ブランチがmainへ取り込まれた後）。
6. `https://memem47.github.io/ActLog/` を開き、クライアントIDを入力してログインします。

> Entraでアプリ登録するには、Microsoft EntraテナントやAzureアカウントの条件を満たす必要があります。個人用Microsoftアカウントだけで管理画面に登録できない場合は、設定を無理に続けず相談してください。課金を伴うAzure契約は自動で行わないでください。

## ローカル起動
VSCodeのターミナルでリポジトリ直下から実行します。

```powershell
python -m http.server 8765
```

ブラウザで `http://localhost:8765/` を開きます。Edenomalyのポート8000とは競合しません。

## 保存データ・注意点
- OneDriveアプリフォルダの `actlog.json` を使用します。
- 保存は都度クラウドへ行い、保存完了メッセージで成功を確認します。
- 通信が切れた状態での記録は未対応です。同期競合の場合は保存を停止し、再読み込みを促します。
- 別端末の最新記録は「最新状態を取得」で反映します。
- 履歴が増えた際は単一JSONファイルからの移行が必要になる可能性があります。
- JSONエクスポートで定期的に手元へバックアップしてください。
- Microsoft Graphのリダイレクトダウンロードがブラウザ環境によって失敗する場合があり、初期版は実機動作確認が必要です。
- GitHub Pagesに公開するのはWeb画面だけです。OneDrive上の記録は公開されません。
- Microsoftのアプリ登録IDは公開可能な識別子ですが、パスワード・シークレット・アクセストークンは共有しないでください。

## 開発方針
v0.1は小さな検証版です。OneDriveの認証・読み書きを実機で確認した後に操作性と信頼性を改善し、将来はExcel履歴移行、カレンダー、統計、CSV出力を追加します。
